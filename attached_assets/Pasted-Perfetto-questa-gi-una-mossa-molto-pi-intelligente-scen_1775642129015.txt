# ⚖️ 2. Differenze chiave: Fermenta vs Yhop

## 🧭 Core prodotto

|                 | Yhop               | Fermenta                                |

👉 **vantaggio tuo:** puoi essere più completo
👉 **vantaggio loro:** sono più semplici

## 🧠 Posizionamento mentale

**Yhop:**
👉 “trova pub/birrifici vicino a te”

**Fermenta (oggi):**

* il tuo è **astratto**

**Yhop:**

**Fermenta:**

* meno “azione immediata”

👉 qui perdi
