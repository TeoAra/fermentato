FERMENTA.TO — UX/UI APP REWORK (PWA + Capacitor)

Obiettivo

Ridisegnare completamente l’esperienza UX/UI di Fermenta.to trasformandola da “sito directory pub” a:

una mobile app craft beer premium, immersiva, fluida e cinematica.

L’app sarà:

* PWA installabile
* compatibile Capacitor
* esportabile APK Android e IPA iOS
* mobile-first
* ultra fluida
* con transizioni native-like
* senza reload percettivi
* ottimizzata per gesture e overlay

⸻

FILOSOFIA UX

L’utente NON deve percepire:

* pagine separate
* reload
* cambio ambiente

Ma:

un’unica superficie interattiva continua.

Ispirazioni:

* Apple Music
* Airbnb
* Revolut
* Arc Browser
* Untappd premium
* VisionOS UI

⸻

ARCHITETTURA UX

STRUTTURA A CONTESTI

NON usare:

* pagine classiche
* menu multipli
* doppie navigazioni

MA:

* navigazione contestuale
* overlay layer
* stack coerente
* bottom nav dinamica

⸻

ROOT APP NAVIGATION

Bottom navigation globale:

* Home
* Explore
* Favorites
* Events
* Profile

Questa navigation esiste solo nella root app.

⸻

PUB EXPERIENCE

Quando entro in un pub:
la bottom navigation cambia contesto.

Diventa:

* Overview
* Spine
* Cantina
* Menu
* Info

IMPORTANTE:

* NON sono pagine
* NON fanno reload
* cambiano sezione tramite:
    * smooth scroll
    * content morph
    * transition fluide

⸻

TOP BAR UX

Design:

minimal, floating, glassmorphism.

Componenti:

Sinistra:

* back gesture/button

Centro:

* logo piccolo o titolo dinamico

Destra:

* search
* favorite
* more/options

⸻

COMPORTAMENTO TOP BAR

Stato espanso:

overlay trasparente sopra hero image.

Scroll:

* hero collapse
* blur progressivo
* title morph
* top bar compatta

Animazione:
120–180ms max.

⸻

SEARCH UX

La search NON deve stare nella bottom bar.

La search è:

globale persistente.

Apertura:

overlay fullscreen con blur.

Tipo:

* Spotlight Apple
* Raycast
* Airbnb search overlay

Deve cercare:

* pub
* birre
* brewery
* eventi
* utenti
* menu
* taplist

UX:

* realtime
* senza pagina nuova
* chiusura torna esattamente nello stesso punto

⸻

BACK SYSTEM

CRITICO.

Il back deve essere:

gerarchico e coerente.

Esempi:

Pub → dettaglio birra overlay
back:
→ chiude overlay

Pub → menu → piatto
back:
→ torna menu

Pub → search overlay
back:
→ chiude overlay

Pub → back root
→ torna esattamente alla schermata origine
