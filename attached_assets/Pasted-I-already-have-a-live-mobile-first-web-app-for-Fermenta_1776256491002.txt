I already have a live mobile-first web app for **Fermenta.to**.
Do **not** build a generic new app from scratch.

Your task is to **redesign and restyle the existing product experience** so it feels much more premium, custom, memorable, and product-led.

## Product context

Fermenta.to is a live local tap finder.

Its main value is:

* helping users discover **what beer is currently on tap nearby**
* making it easy for users to find **real pubs with real live tap lists**
* helping **as many pubs as possible join the platform**
* making the product feel useful immediately

This is **not**:

* a generic beer database
* a brewery magazine
* a social network clone
* a generic food delivery UI

It is a **location-based live beer discovery product**.

## Main redesign objective

I want you to **redesign the current live web app UI** with a much stronger and more personal visual identity.

The result must feel inspired by:

* premium food discovery apps
* restaurant finder apps
* map + list hybrid mobile experiences
* polished editorial product design
* modern craft beer visual culture

But it must **not** feel like:

* a generic AI-generated dashboard
* a basic SaaS layout
* a default Tailwind template
* a sterile startup landing page

## Design direction

Push the UI toward something:

* warmer
* bolder
* more premium
* more atmospheric
* more memorable
* more product-specific

Visual keywords:

* dark premium craft-beer atmosphere
* orange as main accent color
* warm amber highlights
* layered gradients
* depth and glow
* strong hierarchy
* expressive cards
* refined spacing
* more original composition
* more “designed”, less “assembled”

## Product priorities to communicate clearly

The redesigned UI must make these things obvious at first glance:

1. **Nearby**

   * this is about what is around the user right now

2. **Live**

   * tap lists are updated recently
   * freshness matters
   * “updated X min ago” must feel important

3. **On tap**

   * the key value is discovering what is actually available in pubs

4. **For pubs too**

   * pubs should feel invited to join
   * the product should clearly show the benefit of being listed and updating tap lists

## What I want you to redesign

Redesign the app experience with these key areas:

### 1. Main discovery screen

This is the most important screen.

It should include:

* strong visual header / hero area
* location context
* premium search bar
* filter chips
* nearby live beer feed
* beer cards that feel distinctive and premium
* visible distance, pub, and freshness
* clear CTA / tap targets

### 2. Beer cards

Redesign the beer cards so they feel much more unique and product-specific.

Each beer card should communicate:

* beer name
* brewery
* pub
* distance
* freshness

* live availability

The cards should have more personality and visual hierarchy, not just flat text blocks.

### 3. Map + list relationship

Create a stronger connection between:

* beer discovery

* map context

I want a more premium map/list hybrid UX, inspired by high-end nearby discovery apps.

### 4. Pub onboarding / pub CTA

Design a section or component that makes pubs want to join.

The value proposition should be very clear:

* get discovered nearby
* update your tap list quickly
* bring customers in

This should look like a real growth feature, not a weak secondary banner.

### 5. Active pub list / pub cards

Design pub cards with:

* pub name
* neighborhood
* number of taps
* active/live status
* CTA to view tap list
